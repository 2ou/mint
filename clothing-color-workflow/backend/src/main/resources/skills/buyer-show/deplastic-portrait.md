# 去塑料人像

将“真人感”写成可见、可被摄影逻辑解释的细节，而不是堆砌 `ultra realistic`、`perfect skin` 一类空泛词。默认输出英文模型提示词，并用中文说明取舍；用户指定中文提示词时再转换。

## 输入与边界

- 输入可以是现有提示词、参考图描述、目标风格、使用模型，或一张已生成的人像。
- 有参考图时，优先保留人物身份特征、年龄感、肤色、服装和构图；只优化用户指定的区域。
- 若信息不足，默认成年人、非摆拍的日常人像、自然可见光，并说明该假设。
- 不承诺生成图可冒充未编辑的真实摄影；不用于身份、证据或误导性纪实用途。

## 工作流

1. 用一句话诊断主要问题：皮肤、五官/头发、手部姿态、光影、布料道具或画质。
2. 从每个类别挑选少量且互相一致的控制项：皮肤 1–2 项、五官/发丝 1–2 项、姿态/手部 1 项、光线 1 套、衣物/道具 1 项、相机质感 1 套。不要把全部瑕疵词同时写入。
3. 让瑕疵符合环境因果：树影才配叶影和绿色反光；窗边才配窗侧光；傍晚才配暖色反射。选择一种相机语言，不混用 iPhone 直出、胶片和 RAW 原片。
4. 写出正向提示词；模型支持时补充针对性的负向提示词。不要以负向词代替真实的光线、材质和姿态描述。
5. 给出 3–5 条生成后微调建议，并用检查清单核验脸、手、服装和光源是否自然。

详见 [提示词组件与模板](references/prompt-components.md)。

## 输出格式

按以下顺序交付，除非用户只要单条提示词：

1. **问题诊断与取舍**：当前 AI 感来源，以及本次选用的真人细节。
2. **主提示词**：一条可直接复制的完整提示词。
3. **负向提示词 / 避免项**：只列与该图相关的失败模式；不支持负向提示词的模型则改写进主提示词。
4. **局部修改建议**：分别说明皮肤、发丝、手部或背景应如何局部重绘/微调。
5. **验收清单**：光源方向、双手各五指、皮肤细节不过量、布料褶皱和环境反光一致。

## 批量任务中的应用方式（与买家秀 / lookbook 类技能叠加时）

当本技能随 `电商买家秀`、`模特生成`、`women-lookbook-styling` 一起用于**成套提示词**（如一个款式 N 个色号、每份 10 条）时，不逐条输出五段式，改为两种形式应用：

1. **常驻模块**：把去塑料要求写进每条提示词里的固定段落（真实肤质 + 非对称五官 + 单一相机语言 + 一个受控瑕疵），而不是事后补充。
2. **文档级建议**：在整份文档末尾给一处「生成后局部微调建议」（3–5 条，覆盖皮肤 / 发丝 / 手部 / 布料道具 / 阴影），供整批通用。

`问题诊断` 只在用户是要**改已生成的一张图**时才单列输出。

## 成功标准

- 皮肤保留微小纹理和局部油光，但不脏、不显病态、不夸张增加年龄感。
- 五官与参考人物一致，只呈现自然微差，避免强行改脸。
- 阴影、环境反光、景深、颗粒和动态来自同一拍摄条件。
- 手部解剖正确、动作有重心，服装和道具带有限度的自然磨损与褶皱。
