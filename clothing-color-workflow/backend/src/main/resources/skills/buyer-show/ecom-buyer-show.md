# 亚马逊/沃尔玛买家秀

生成“普通消费者真实穿着、用手机在日常空间拍摄”的服装图片。把真实性建立在拍摄语法、人物状态、服装受力和环境逻辑上，而不是依赖低画质、遮脸或夸张瑕疵。

## 参考路由

- 首次处理样本分析、买家秀风格诊断或真实性解释时，完整读取 \`references/sample-findings.md\`。
- 写提示词或直接生成图片时，完整读取 \`references/prompt-patterns.md\`。

## 决策优先级

1. 用户明确要求。
2. 商品参考图的服装事实。
3. 完整脸部与安全裁剪空间。
4. 买家秀真实感。
5. 可选的审美与人物风格。

当本技能与 \`模特生成\`（fashion model generator）同时适用时：

- 继承其服装保真、真实肤质、体型/年龄/族裔多样性和负面约束。
- 覆盖其“专业模特基线”和“默认数据卡三视图”：买家秀使用普通消费者、自然姿态、单张手机照片。
- 只有用户明确要求专业模特或三视图时，才恢复对应规则。

## 模特参考图：服装锁定与姿势重置

当参考图是“模特已穿着商品”的图片时，先把输入拆成两类信息：

- **仅可继承的服装事实**：颜色、印花、面料、领口、袖型、长度、版型、缝线、口袋和其他可见结构。
- **默认必须舍弃的非服装信息**：原人物的脸、身份、发型、体型、姿势、手部位置、相机角度、房间、家具、光线、构图和配饰。

除非用户明确说“保持动作/姿势不变”，所有带模特的参考图都必须执行 **姿势重置**：

1. 在每条生成提示词开头写明：`Use the attached image only as the garment source of truth. Do not inherit or recreate the reference person's identity, face, body, hairstyle, pose, hand placement, camera angle, background, lighting, or composition.`
2. 为输出指定全新的人物、动作、拍摄者位置、房间和光线；不要只写泛泛的 `standing naturally`，要写清晰的重心、躯干方向、手部动作和场景关系。
3. 参考图中若为双手插袋、叉腰、拿杯子或特定站姿，生成图必须换成不同动作。仅当服装明确有口袋且用户要求展示口袋时，才为口袋设计专门手势；不得把口袋或插袋动作设为默认卖点。
4. 生成后进行“姿势去继承”检查：输出与参考图至少应在人物身份、发型、拍摄方式、机位、房间、躯干朝向、手部动作、重心、光线中改变 5 项；服装事实必须保持一致。

## 工作流

1. **识别输出**
   - 用户要求“分析”：说明样本共同机制，不生成图片。
   - 用户要求“写提示词”：交付服装分析、场景选择、英文 Prompt、Negative Prompt。
   - 用户要求“生成/出图/N 张”：直接调用图片生成工具；每张使用独立提示词。

2. **读取输入**
   - 对本地服装图先用图像查看工具逐张检查。
   - 对样本文件夹先盘点数量、格式、尺寸和元数据，再制作缩略总览并抽查原图。
   - 不把具体样本人物的脸、家庭、纹身、宠物或私人物品复制到新图；只学习通用机制。

3. **锁定商品**
   - 以参考图为唯一服装事实来源。
   - 锁定颜色、印花比例与位置、领型、袖型、门襟、腰头、裤型/裙型、长度、面料、缝线、口袋和宽松度。
   - 多图必须每张重复完整服装描述，不写 “same as above”。
   - 若参考图含人物，明确列出“服装外观来源”和“禁止继承的原图信息”；禁止把原图姿势、手势或卧室构图当作商品事实。

4. **选择买家拍摄模式**
   - 镜面自拍、门口/卧室站立、沙发/床边坐姿、厨房/玄关倚靠、阳台/窗边试穿。
   - 默认竖版 3:4 手机照片；除非用户另有比例要求。
   - 不自动使用影棚、时尚大片、极浅景深或专业走秀姿势。

5. **建立普通消费者人物**
   - 使用 \`ordinary adult customer\`、\`real everyday wearer\` 或 \`casual at-home try-on\`。
   - 按商品尺码选择自然标准、柔和曲线或大码体型；用户未指定时不要默认大码。
   - 表情、发型、妆容和姿态保持自然、松弛、略带个人习惯，避免网红脸和职业模特气场。

6. **编译提示词**
   - 使用 \`references/prompt-patterns.md\` 的顺序和场景块。
   - 每张只加入 1 个受控手机摄影缺陷；真实感不等于堆叠噪点、模糊和脏乱。
   - 同时写基础 Negative Prompt 和与场景匹配的轮换组。
   - 对模特参考图，必须加入姿势重置段与 \`do not recreate the reference pose / hand placement / composition\` 负面约束。

7. **生成与检查**
   - 直接生成时遵循图片生成工具（ImageGen）的输入、保存和回复规则。
   - 检查完整脸部、商品一致性、手指、手机、镜像、家具几何、布料折痕、身体接触阴影和背景合理性。
   - 检查输出动作是否不必要地复刻参考图；如有复刻，保留服装锁定内容，只重写动作和场景块后再生成。
   - 失败时只针对一个主要问题迭代，不重写全部风格。

## 硬规则

### 完整脸部

- 默认完整显示头顶、额头、双眼、鼻子、嘴、下巴和两侧脸部轮廓。
- 画面上方保留约 8%–12% 安全裁剪空间；不要切掉头顶或下巴。
- 镜面自拍时手机放在脸侧或胸前，不遮挡五官。
- 头发可以自然遮住小部分脸侧，但不能遮住双眼和主要面部结构。
- 用户后续自行裁剪；本技能不得用“遮脸/裁脸”作为默认反 AI 手段。

### 买家秀真实感

- 保留自然身体比例、腹部与大腿体积、手臂放松状态和轻微姿态不对称。
- 表现衣服在肩、胸、腰、胯、坐姿和抬臂处的真实褶皱、拉伸、堆叠、接触阴影与重力垂坠。
- 使用普通住宅尺度与有生活痕迹但不过度杂乱的背景。
- 光线允许不均、混合色温和轻微曝光偏差，但脸部与商品必须清楚。
- 使用手机广角或标准镜头的轻微透视，保持环境较深景深。
- 允许自然 JPEG 压缩、细微手机噪点或轻微构图倾斜中的一项；不要同时堆叠。

### 禁止伪装

- 不生成星级、评论正文、用户名、订单截图、Verified Purchase 标签或“真实买家证明”。
- 不声称合成图片来自真实客户、真实订单或真实评价。
- 不复制样本人物身份，不创建可用于冒充特定个人的内容。
- 当用途涉及评论发布或买家背书时，提示用户遵守平台规则并清晰披露合成/商业关系。

## 多图规则

- 同一商品保持服装不变，人物身份、住宅、动作、光线和拍摄方式变化。
- 第 2 张起至少变化 5 项：年龄、族裔、体型、发型、房间、拍摄模式、姿态、光线、手机位置、构图倾斜。
- 默认 6 张组合：2 张完整脸部镜面自拍、1 张门口站立、1 张厨房/玄关倚靠、1 张沙发/床边坐姿、1 张窗边/阳台环境照。
- 每张都是单一完整照片；不要拼贴、数据卡、三视图或在图内添加文字。

## 输出

用户要提示词时，依次输出：

1. 商品保真摘要。
2. 买家秀拍摄方案。
3. 每张独立英文 Prompt。
4. 每张 Negative Prompt。
5. 完整脸部与合成内容边界检查。

用户要直接生成图片时，不要求再次确认；按图片生成工具的回复规则执行。
