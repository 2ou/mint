# 买家秀样本规律

## 样本范围

- 来源：用户桌面 `买家秀` 文件夹中的 14 张服装买家秀照片。
- 画幅：全部为 1340 × 1785，接近 3:4 竖图。
- 元数据：样本未保留可用的相机、手机或软件 EXIF 信息。
- 用途：总结可迁移的拍摄语法与服装穿着可信度，不复制某一位人物、住宅、纹身、宠物或其他可识别特征。
- 说明：视觉分析只能解释“为什么看起来像真实买家拍摄”，不能仅凭图片证明其平台来源或真实身份。

## 样本中的主要拍摄模式

大致可分为：

- 7 张镜前自拍或手持手机自拍；
- 2 张坐在沙发、床边等位置的随手拍；
- 4 张在卧室、门口、厨房等室内区域站立或倚靠的照片；
- 1 张阳台或窗边生活场景照片。

这些图片的共同点不是“低画质”，而是画面中的人物、服装、光线、空间和手机成像逻辑彼此一致。

## 逼真感来自哪里

| 层面 | 样本特征 | 对生成的启示 |
|---|---|---|
| 拍摄设备感 | 典型手机竖拍，标准或略广角视野，景深较深 | 使用普通智能手机成像，不用电影镜头、长焦压缩或强虚化 |
| 构图 | 轻微倾斜、人物不完全居中、空间留白不绝对均匀 | 允许一种受控的随手拍偏差，但主体和服装仍需完整可读 |
| 家居环境 | 卧室、浴室、厨房、门口、沙发、阳台；有少量生活用品 | 场景要可居住、可使用，加入少量合理物件，不堆砌杂乱 |
| 光线 | 窗光与室内灯混合，局部明暗不完全均匀 | 保留自动曝光和轻微混合白平衡，避免棚拍轮廓光和广告级布光 |
| 人物 | 普通成年女性，不同体型；姿态放松且略不对称 | 使用 ordinary customer，而不是职业模特、网红脸或夸张沙漏身材 |
| 服装与身体 | 腰头、腋下、胸腰、裆部、臀腿处有合理拉伸、堆褶和接触阴影 | 重点描述重力、压力点、褶皱走向与印花随布料弯曲 |
| 造型 | 日常发型、自然妆感、简单首饰或手机壳 | 造型应像在家试穿，不能抢过商品主体 |
| 图像质感 | 细节足够看清，带轻微手机锐化、噪点或 JPEG 感 | 不使用“8K、HDR、极致锐利、电影级、超写实皮肤”等过度指令 |

## 保留脸部的用户规则

部分样本通过裁头或手机遮脸强化了自拍感，但本技能不沿用这一做法。所有生成结果默认：

- 从头顶到下巴完整可见；
- 头顶上方预留约 8%–12% 的安全裁剪空间；
- 手机放在脸侧、胸前或略低位置，不遮挡眼睛、鼻子和嘴巴；
- 保留自然五官、皮肤纹理和轻微表情，不生成磨皮塑料脸；
- 用户可在成图后自行裁剪。

## 可迁移的真实感配方

按以下顺序建立可信度：

1. 锁定服装颜色、印花、面料、廓形、结构和长度。
2. 选择普通成年顾客及与服装尺码相符的自然体型。
3. 放入一个可解释的真实家居位置。
4. 给人物一个简单日常动作或轻微不对称站姿。
5. 完整保留脸部和头顶裁剪空间。
6. 使用手机深景深、自动曝光和不完全均匀的生活光。
7. 让服装在身体压力点产生方向正确的拉伸、褶皱和接触阴影。
8. 只加入一种受控手机瑕疵，例如轻微倾斜、少量噪点、轻微曝光偏差或柔和 JPEG 压缩感。

## 默认六张组合

在用户未指定镜头数量时，可给出六张互不重复的单图方案：

1. 卧室或衣帽区镜前自拍，手机位于脸侧；
2. 门口或走廊自然站立，家人视角手机随拍；
3. 厨房或玄关轻倚台面，身体略侧转；
4. 沙发或床边坐姿，展示服装落座后的褶皱；
5. 窗边或阳台自然光站姿；
6. 轻微走动、整理袖口或触碰腰头的生活动作。

每张只生成一个画面，不能拼贴、不能三视图、不能数据卡排版。

## 常见失真模式

- 职业模特台步、广告式摆拍、强烈网红表情；
- 无缝棚拍背景、电影布光、明显轮廓光、强浅景深散景；
- 家居空间过度整洁、豪宅样板间化，或杂物无逻辑堆满画面；
- 皮肤塑料化、毛孔被过度强调、全身细节锐化过度；
- 体型与服装尺码不匹配，布料像贴图一样悬浮；
- 腰头、裆部、腋下、胸腰、臀腿的褶皱方向与身体受力矛盾；
- 镜中手机、手指、家具或门框发生不可能的反射与变形；
- 同时叠加倾斜、模糊、重噪点、欠曝等多种瑕疵，刻意制造“假随手拍”；
- 裁掉头顶、下巴或用手机遮住整张脸；
- 复制样本人物的身份特征或住宅细节。
