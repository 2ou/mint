# 女装视频故事板模板

## 故事板格式说明

故事板 = 分镜图提示词 + 视频脚本 + Seedance提示词

每个分镜包含：
- **分镜图提示词**：用于Midjourney/DALL-E生成首帧图片（英文）
- **视频脚本**：运镜方式 + 画面描述 + 动作 + 对白 + 特效
- **Seedance提示词**：直接复制到即梦AI生成视频（中文）

---

## 检查清单

### 视觉一致性
- [ ] 所有分镜的模特形象保持一致
- [ ] 服装在所有分镜中保持相同状态
- [ ] 光线和色调保持统一
- [ ] 场景环境保持连贯

### 技术规范
- [ ] 每个分镜时长≤11秒
- [ ] 提示词字数≤500字
- [ ] 首帧图片已准备
- [ ] 参数设置合理

### 内容质量
- [ ] 故事逻辑清晰
- [ ] 产品卖点突出
- [ ] 运镜方式合理
- [ ] 节奏把控得当
