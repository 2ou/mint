# 女装面料材质词库

## 天然面料

### Cotton（棉）
**特性**：柔软、透气、舒适、易护理
**适用款式**：T恤、衬衫、连衣裙、休闲装
**质感关键词**：Soft, Breathable, Casual, Everyday, Comfortable
**视觉特点**：自然纹理，轻微褶皱，哑光质感
**提示词示例**：
```
Close-up of cotton fabric texture, soft and breathable material, 
natural fibers visible, comfortable and casual feel, 
slight wrinkles showing natural drape, matte finish
```

### Linen（亚麻）
**特性**：轻盈、透气、自然、夏季首选
**适用款式**：衬衫、连衣裙、裤子、度假装
**质感关键词**：Lightweight, Summer, Relaxed, Natural, Breezy
**视觉特点**：明显纹理，自然褶皱，透气感
**提示词示例**：
```
Linen fabric close-up showing natural texture and weave, 
lightweight and breathable material, relaxed summer feel, 
visible fiber texture, soft and comfortable drape
```

### Silk（丝）
**特性**：奢华、优雅、垂坠感好、有光泽
**适用款式**：衬衫、连衣裙、睡衣、晚装
**质感关键词**：Luxurious, Elegant, Drapes beautifully, Sheen, Premium
**视觉特点**：光泽感，流畅垂坠，细腻质感
**提示词示例**：
```
Silk fabric catching light with beautiful sheen, 
elegant drape and flow, luxurious texture, 
smooth and refined surface, premium quality material
```

### Wool（羊毛）
**特性**：保暖、有结构感、冬季首选
**适用款式**：毛衣、外套、西装、大衣
**质感关键词**：Warm, Structured, Winter, Cozy, Premium
**视觉特点**：细腻纹理，温暖质感，有结构感
**提示词示例**：
```
Wool fabric showing fine texture and structure, 
warm and cozy material, premium quality, 
visible fiber detail, elegant and refined appearance
```

### Cashmere（羊绒）
**特性**：超柔软、轻盈、保暖、高端
**适用款式**：毛衣、围巾、外套、高端针织
**质感关键词**：Ultra-soft, Premium, Lightweight warmth, Luxury
**视觉特点**：细腻绒毛，柔软质感，高端感
**提示词示例**：
```
Cashmere fabric ultra-close showing incredibly soft texture, 
luxurious and lightweight material, premium quality, 
delicate fiber structure, elegant and refined appearance
```

## 合成面料

### Polyester（涤纶）
**特性**：抗皱、耐用、易护理、色彩鲜艳
**适用款式**：运动装、连衣裙、外套、工作服
**质感关键词**：Wrinkle-resistant, Durable, Easy care, Versatile
**视觉特点**：光滑表面，色彩饱满，易打理
**提示词示例**：
```
Polyester fabric showing smooth and durable texture, 
wrinkle-resistant material, vibrant color retention, 
versatile and practical, easy-care quality
```

### Nylon（尼龙）
**特性**：轻盈、速干、耐磨、运动感
**适用款式**：运动装、外套、泳装、户外装
**质感关键词**：Lightweight, Quick-dry, Sporty, Durable
**视觉特点**：光滑表面，轻薄质感，运动感
**提示词示例**：
```
Nylon fabric showing lightweight and smooth texture, 
quick-drying material, sporty and modern feel, 
durable and practical, athletic quality
```

### Spandex（氨纶）
**特性**：高弹力、贴身、运动感
**适用款式**：运动装、紧身衣、泳装、内衣
**质感关键词**：Stretchy, Form-fitting, Activewear, Flexible
**视觉特点**：贴身效果，弹性质感，运动感
**提示词示例**：
```
Spandex fabric showing high elasticity and stretch, 
form-fitting material, activewear quality, 
smooth and flexible texture, athletic and modern
```

### Rayon（人造丝）
**特性**：柔软、垂坠感好、透气
**适用款式**：连衣裙、衬衫、休闲装
**质感关键词**：Soft, Drapes well, Breathable, Comfortable
**视觉特点**：流畅垂坠，柔软质感，自然光泽
**提示词示例**：
```
Rayon fabric showing beautiful drape and flow, 
soft and breathable material, comfortable feel, 
natural sheen and movement, elegant appearance
```

## 面料质感提示词技巧

### 质感描述要素
1. **触感**：Soft, Smooth, Rough, Textured, Silky
2. **视觉**：Matte, Shiny, Sheen, Glossy, Lustrous
3. **垂坠**：Drapes well, Stiff, Flowy, Structured, Fluid
4. **重量**：Lightweight, Heavy, Medium-weight, Airy
5. **纹理**：Fine, Coarse, Woven, Knit, Twill

### 动态质感描述
- **飘动**：Flowing, Billowing, Fluttering, Swaying
- **褶皱**：Wrinkles, Folds, Pleats, Draping
- **光泽变化**：Light-catching, Shimmering, Glinting
- **质感对比**：Smooth vs. Textured, Matte vs. Shiny

### 组合提示词示例
```
Silk blouse with beautiful drape and sheen, 
fabric flowing gracefully with movement, 
light-catching texture, elegant and luxurious feel
```

```
Denim jacket with rugged texture and casual appeal, 
slightly worn look with natural fading, 
durable and versatile material, classic American style
```

```
Cashmere sweater showing incredibly soft texture, 
lightweight warmth with premium quality, 
delicate fiber structure visible, cozy and luxurious
```
