## 模特姿态库

### 站姿
1. **自然站立**：重心在一脚，另一脚微弯，身体微侧
2. **自信站姿**：双脚与肩同宽，挺胸抬头，双手叉腰或自然下垂
3. **休闲站姿**：一脚交叉于前，身体微斜，手插口袋
4. **优雅站姿**：一脚前伸，脚尖点地，身体形成S曲线

### 坐姿
1. **优雅坐姿**：双腿交叉，背部挺直，双手自然放置
2. **休闲坐姿**：双腿并拢微斜，身体放松，手托下巴
3. **商务坐姿**：双腿并拢，双手交叠于膝，专注表情

### 动态姿态
1. **行走**：自然步态，手臂摆动，头发微动
2. **转身**：身体旋转，裙摆飘动，回眸一笑
3. **互动**：与环境互动，触摸面料，整理衣物
