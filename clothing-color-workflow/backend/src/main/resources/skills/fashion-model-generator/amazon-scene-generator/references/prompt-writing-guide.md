# 提示词写作最佳实践指南

## 四大基础要素

### 1. 主体描述（Subject）

#### 人物特征
**基本要素**：
- 年龄：30-35岁、36-45岁、46-55岁
- 族裔：Caucasian、African American、Latina、Asian American、Mixed
- 体型：slim、athletic、curvy、plus-size
- 表情：confident、relaxed、happy、serious、gentle

**面部细节**：
```
Natural makeup, [lipstick color] lips, [eye color] eyes, 
[hairstyle: straight/curly/wavy] [hair color] hair, 
[glasses/jewelry if applicable]
```

**姿态描述**：
```
[Standing/walking/sitting/leaning], 
[Arms: crossed/at sides/in pockets/hands on hips], 
[Head: tilted/straight/turned], 
[Gaze: at camera/away/down/interaction]
```

#### 服装描述
**结构要素**：
```
[款式] [颜色] [面料] [细节]
```

**示例**：
```
Tailored navy blue wool blazer with notch lapel, 
two-button closure, front flap pockets
```

**完整服装描述**：
```
Top: [款式] [颜色] [面料] [领口/袖口细节]
Bottom: [款式] [颜色] [面料] [长度/剪裁]
Shoes: [款式] [颜色] [跟高]
Accessories: [项链/耳环/手链/手表/包包]
```

---

### 2. 环境设定（Environment）

#### 场景描述
**空间层次**：
```
Foreground: [前景元素，如桌子、栏杆]
Midground: [中景，人物所在位置]
Background: [背景，如建筑、自然景观]
```

**场景要素**：
- 地点：具体名称（如"modern office"、"cozy coffee shop"）
- 风格：modern、rustic、minimalist、bohemian
- 道具：相关物品增强真实感

**示例**：
```
Modern open-plan office with floor-to-ceiling windows, 
minimalist desk with laptop and coffee cup, 
green plants in corners, city skyline visible through windows
```

#### 光线设定
**光线方向**：
- Front lighting：正面光，均匀照亮
- Side lighting：侧光，增加立体感
- Backlight：逆光，轮廓光、梦幻
- Top lighting：顶光，特殊效果
- Rim lighting：边缘光，分离背景

**光线质感**：
- Hard light：硬光，边缘清晰
- Soft light：柔光，过渡自然
- Dappled light：斑驳光，树荫效果
- Diffused light：漫射光，均匀柔和

**光线色温**：
- Warm light：暖光，温馨浪漫
- Cool light：冷光，现代专业
- Neutral light：中性光，真实自然
- Golden light：金色光，黄金时刻

**示例**：
```
Soft natural light from large windows, 
warm golden hour glow, 
gentle shadows on one side of face, 
dappled sunlight through trees
```

### 3. 构图与视角（Composition）

#### 镜头距离选择
根据展示目的选择：

**产品特写**：ECU/CU
- 突出面料细节、配饰、妆容
- 适合A+页面细节图

**半身展示**：MCU
- 上身效果、表情、搭配
- 适合亚马逊主图

**全身展示**：LS
- 完整搭配、姿态、环境
- 适合生活方式图

#### 镜头角度选择
**平视（Eye Level）**：
- 最自然、亲切
- 适合大多数场景
- 提示词：`eye-level angle, natural perspective`

**仰视（Low Angle）**：
- 显得高大、有气势
- 适合职业装、晚装
- 提示词：`low angle, powerful perspective`

**俯视（High Angle）**：
- 显得小巧、可爱
- 适合休闲装、亲密感
- 提示词：`high angle, intimate perspective`

#### 景深控制
**浅景深（Shallow DOF）**：
- 主体清晰，背景虚化
- 突出人物和服装
- 提示词：`shallow depth of field, bokeh background`

**深景深（Deep DOF）**：
- 前后都清晰
- 展示环境和故事
- 提示词：`deep depth of field, everything in focus`

## 去塑料感技巧

### 1. 真实皮肤
**问题**：AI生成的皮肤过于光滑、完美
**解决**：
```
Natural skin texture, visible pores, 
subtle skin imperfections, realistic skin tone, 
no airbrushing, authentic appearance
```

**示例**：
```
Woman with natural skin texture, 
visible pores on cheeks and nose, 
subtle freckles across bridge of nose, 
realistic skin with minor imperfections, 
no airbrushing or smoothing
```

### 2. 自然光影
**问题**：光影过于均匀、不真实
**解决**：
```
Soft natural lighting, realistic shadows, 
light falloff, no harsh edges, 
natural color temperature, 
shadows following light direction
```

**示例**：
```
Soft natural light from window, 
gentle shadows on left side of face, 
light falloff on neck and shoulders, 
realistic shadow under chin, 
natural warm color temperature
```

### 3. 环境真实感
**问题**：场景过于完美、不真实
**解决**：
```
Realistic environment details, 
natural wear and tear, authentic textures, 
lived-in feel, not overly staged,
minor imperfections for authenticity
```

**示例**：
```
Cozy coffee shop with slightly worn wooden tables, 
coffee rings on surface, 
well-used furniture with natural patina, 
books with creased spines, 
authentic and lived-in atmosphere
```

### 4. 自然姿态
**问题**：姿态过于僵硬、不自然
**解决**：
```
Natural pose, relaxed posture, 
genuine expression, candid moment, 
not overly posed, slight asymmetry, 
natural hand placement
```

**示例**：
```
Woman in relaxed pose, 
weight shifted to one hip, 
arms naturally at sides, 
slight head tilt, 
genuine smile reaching eyes, 
candid and authentic moment
```

## 镜头语言详解

### 焦距选择
**广角（Wide Angle, 18-35mm）**：
- 视角宽，空间感强
- 适合环境人像、场景展示
- 提示词：`wide angle lens, environmental portrait`

**标准（Standard, 50mm）**：
- 最接近人眼视角
- 适合日常场景、自然感
- 提示词：`50mm lens, natural perspective`

**中长焦（Medium Telephoto, 85-135mm）**：
- 人像摄影黄金焦段
- 适合半身、特写，畸变小
- 提示词：`85mm lens, portrait photography`

**长焦（Telephoto, 200mm+）**：
- 压缩空间，背景虚化强
- 适合时尚摄影、突出主体
- 提示词：`telephoto lens, compressed background`

### 景深控制
**浅景深（f/1.4-f/2.8）**：
```
Shallow depth of field, f/1.8, 
creamy bokeh background, 
subject in sharp focus, 
isolation from background
```

**中等景深（f/4-f/8）**：
```
Medium depth of field, f/5.6, 
subject sharp, background slightly soft, 
balanced focus, natural look
```

**深景深（f/11-f/16）**：
```
Deep depth of field, f/11, 
everything in focus from foreground to background, 
sharp details throughout, landscape style
```

### 快门速度
**快速快门（1/500s+）**：
```
Fast shutter speed, frozen motion, 
sharp and crisp, action photography, 
no motion blur
```

**慢速快门（1/30s-1s）**：
```
Slow shutter speed, motion blur, 
sense of movement, artistic effect, 
[subject] in motion
```

## 常见问题解决

### Q1：人物看起来不真实
**解决方案**：
1. 添加真实皮肤描述：`natural skin texture, visible pores`
2. 添加自然瑕疵：`subtle imperfections, minor blemishes`
3. 添加自然姿态：`relaxed posture, genuine expression`
4. 使用负向词：`no airbrushing, no plastic skin`

### Q2：服装细节丢失
**解决方案**：
1. 详细描述服装：面料、剪裁、细节
2. 指定光线突出面料：`light catching fabric texture`
3. 使用特写镜头：`close-up shot for details`
4. 添加面料关键词：`soft/smooth/textured [fabric]`

### Q3：场景看起来假
**解决方案**：
1. 添加真实感细节：`lived-in space, natural wear`
2. 添加环境道具：`books, plants, personal items`
3. 使用自然光线：`natural light, realistic shadows`
4. 避免过度完美：`minor imperfections for authenticity`

### Q4：风格不一致
**解决方案**：
1. 使用统一的风格关键词
2. 保持光线类型一致
3. 使用相似的构图方式
4. 参考同一摄影师/风格

### Q5：AI痕迹明显
**解决方案**：
1. 强调真实感：`realistic, authentic, natural`
2. 添加质感描述：`texture, detail, depth`
3. 使用专业摄影术语
4. 添加负向词排除AI特征

- [ ] 构图明确（镜头距离、角度、景深）

- [ ] 皮肤质感描述（毛孔、瑕疵、自然色调）
