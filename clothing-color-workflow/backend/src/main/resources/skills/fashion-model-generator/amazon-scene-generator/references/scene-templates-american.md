## 🔧 使用说明

### 变量说明

| 变量 | 说明 | 美式风格建议 |
|------|------|--------------|
| `[年龄]` | 模特年龄 | 30-55岁，自信成熟 |
| `[动作]` | 模特动作 | 自然、放松、有动感 |
| `[服装描述]` | 服装详情 | 符合场景的美式穿搭 |
| `[表情描述]` | 表情状态 | 自信、自然、真诚微笑 |
| `[发型描述]` | 发型细节 | 自然、不做作 |
| `[镜头]` | 镜头距离 | 根据场景选择 |
| `[光线]` | 光线类型 | 自然光优先 |

### 美式风格强调词

每个提示词都应包含以下至少2-3个：
```
American lifestyle, authentic, natural,
confident, empowering, body positive,
realistic skin texture, no airbrushing,
warm golden tones, editorial quality,
aspirational but relatable
```

### 负向提示词（美式专用）

```
no Asian style, no Chinese aesthetic,
no porcelain white skin, no overly thin body,
no cute poses, no forced smile,
no heavy filter, no over-retouching,
no plastic appearance, no artificial look,
no cartoon, no anime, no illustration,
no low quality, no blurry, no distorted,
no watermark, no text, no logo
```
