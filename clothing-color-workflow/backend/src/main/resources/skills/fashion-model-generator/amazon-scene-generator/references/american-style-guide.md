## 🎨 美式审美特征

### 人物气质
| 特征 | 描述 | 关键词 |
|------|------|--------|
| **自信** | 独立、强大、有魅力 | confident, empowered, strong |
| **自然** | 真实、不做作、亲切 | natural, authentic, approachable |
| **健康** | 活力、阳光、运动 | healthy, active, sun-kissed |
| **多元** | 身材包容、多样化 | body positive, diverse, inclusive |

### 视觉风格
| 维度 | 美式特征 | 避免 |
|------|----------|------|
| **光线** | 自然光、黄金时刻、柔和阴影 | 过度打光、均匀无影 |
| **色彩** | 温暖自然、大地色、柔和粉彩 | 过度饱和、滤镜厚重 |
| **质感** | 真实皮肤、自然纹理、生活感 | 过度磨皮、塑料感 |
| **构图** | 自然随意、有动感、真实场景 | 过度摆拍、僵硬姿势 |

### 色彩搭配

#### 经典美式配色
```
Neutral: white, cream, beige, gray, navy, black
Earth tones: tan, olive, rust, terracotta, sage
Soft pastels: blush, lavender, sky blue, mint
Warm metallics: gold, brass, copper
```

#### 季节配色
```
Spring: soft pink, lavender, mint, butter yellow
Summer: coral, turquoise, white, navy
Fall: rust, burgundy, olive, mustard
Winter: emerald, cranberry, silver, evergreen
```

## 🚫 禁止的中式元素

### 场景
- ❌ 中式园林、假山、亭子
- ❌ 四合院、中式建筑
- ❌ 中式家具（红木、屏风）
- ❌ 中式装饰（灯笼、对联）

### 人物
- ❌ 过度白皙的皮肤
- ❌ 过度纤细的身材
- ❌ 嘟嘴、卖萌表情
- ❌ 僵硬的姿势

### 风格
- ❌ 网红风格
- ❌ 过度滤镜
- ❌ 过度磨皮
- ❌ 高饱和度色彩

## ✅ 美式风格检查清单

### 场景
- [ ] 场景地点在美国（纽约、洛杉矶、迈阿密等）
- [ ] 使用美式建筑和室内设计
- [ ] 道具符合美式生活（咖啡杯、牛仔、棒球帽等）
- [ ] 自然光线、真实环境

### 人物
- [ ] 自信、自然的表情
- [ ] 健康、阳光的气质
- [ ] 真实的皮肤质感（毛孔、瑕疵）
- [ ] 自然的姿势和动作

### 风格
- [ ] 温暖自然的色调
- [ ] 真实质感，无塑料感
- [ ] 生活化场景，非过度摆拍
- [ ] 美式生活方式体现
