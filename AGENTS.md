# Project Frontend Instructions

For frontend page work in this project, use the installed `finesse-ui` skill as the design workflow.

- Skill path: `C:\Users\Administrator\.codex\skills\finesse-ui\SKILL.md`
- Default register for this project: `product`
- Prioritize clarity, density, usability, stable workflows, admin efficiency, and polished component states.
- Avoid marketing-style landing pages, oversized heroes, decorative repeated cards, cheap gradients, default glassmorphism, and generic AI-looking dashboards.
- For A+ and internal admin pages, preserve existing business logic, API paths, request fields, response fields, and backend contracts.
- New or refactored frontend components should follow the existing project stack first, and use shadcn-vue + Tailwind CSS style where applicable.
- When applying `finesse-ui`, load only the references needed for the task, usually `references/product-ui.md`, `references/design-dna.md`, `references/anti-cheap.md`, and `references/preflight.md`.
- Use local test port `8081` when running the project for UI checks; do not occupy `8080`.
